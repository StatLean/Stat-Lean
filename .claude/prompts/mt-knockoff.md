## The theorem (Lu-BDA §19, `thm:knockoff`)
For a knock-off score `W` (Def. `kos` cond. 3: null signs i.i.d. `Ber(½)` given magnitudes,
encoded by `KnockoffScore.signs_*`), the procedure rejecting `S⁺(t*)`,
`t* = min{t : FDPhat(t) ≤ α}`, `FDPhat(t) = (#S⁻(t)+1)/(#S⁺(t)∨1)`, controls FDR: `E[FDP] ≤ α`.

## Verbatim book proof (translate to Lean)
With `V±(t) = #{j∈H₀ : j∈S±(t)}`:
```
FDP(t*) = (#{j∈H₀:j∈S⁺(t*)})/(#{j:j∈S⁺(t*)}) · (1+#{j∈H₀:j∈S⁻(t*)})/(1+#{j∈H₀:j∈S⁻(t*)})
        ≤ FDPhat(t*) · V₊(t*)/(1+V₋(t*))   ≤   α · V₊(t*)/(1+V₋(t*)).
```
(That is `knockoff_fdp_le`, deterministic: uses `#{j∈H₀:S⁺}≤#{j:S⁺}`, `FDPhat(t*)≤α` by def of
`t*`, and `1+#{j∈H₀:S⁻} ≤ 1+#{j:S⁻}`.) So it suffices that `E[V₊(t*)/(1+V₋(t*))] ≤ 1`
(`knockoff_ratio_stopped_le_one`).

**The supermartingale step (the heart).** Conditional on the magnitudes `|W|`, the null signs are
i.i.d. `Ber(½)`, so `V₊(t) ∣ V₊(t)+V₋(t)` is hypergeometric. Sweep the threshold *downward*
through the sorted magnitudes; let `𝓕_t` carry "which `|Wⱼ|>t` are null" and `V₊(t)+V₋(t)`. Then
for `s ≥ t`, `E[V₊(s)/(1+V₋(s)) ∣ 𝓕_t] ≤ V₊(t)/(1+V₋(t))`, i.e. `V₊/(1+V₋)` is a supermartingale.
By the optimal stopping theorem (`thm:optstop`),
`E[V₊(t*)/(1+V₋(t*))] ≤ E[V₊(0)/(1+V₋(0))] ≤ 1`.
