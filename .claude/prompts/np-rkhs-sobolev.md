## Proof guidance — Sobolev

Model recap: `sobolevMeasure = volume.restrict (Icc 0 1)`;
`sobolevOne = 𝟙_univ·1 ∈ L²`; `sobolevInd x = 𝟙_{Icc 0 x}·1`;
`SobolevH01 = (ℝ ∙ sobolevOne)ᗮ`; coeCLM g = fun x => ⟪sobolevInd x, g⟫.

- `coeCLM_injective`: suppose `g ∈ (ℝ∙1)ᗮ` with `⟪𝟙_{[0,x]}, g⟫ = 0` for all
  `x ∈ [0,1]`.  Then `∫_{s} g = 0` for `s` in the π-system `{Icc 0 x}`; together with
  `∫_{[0,1]} g = 0` (from `g ⊥ 1`) get `∫_{Ioc x y} g = 0` on all subintervals by
  subtraction, hence `g = 0` a.e. — use
  `MeasureTheory.ae_eq_zero_of_forall_setIntegral_eq_zero`-family
  (`Mathlib/MeasureTheory/Function/AEEqOfIntegral.lean`) or the π-system/dynkin route
  `MeasureTheory.induction_on_inter` over the Borel σ-algebra of `[0,1]` generated by
  `Icc 0 x`.  A convenient alternative: the primitive `F(x) = ∫_{[0,x]} g` vanishes on
  a dense set and is continuous, and `intervalIntegral`-based lemmas like
  `MeasureTheory.ae_eq_zero_of_forall_...`; if you find the σ-algebra route heavy,
  prove instead that the span of `{sobolevInd x} ∪ {sobolevOne}` is dense in
  `L²(sobolevMeasure)` (step functions are dense: search
  `MeasureTheory.Lp.simpleFunc.dense`, `SimpleFunc.dense...`) and conclude
  `g ⊥ dense span ⇒ g = 0`.  Either way, extract reusable `private` lemmas.
- `sobolevH01_apply`: unfold: `⟪sobolevInd x, g⟫ = ∫ 𝟙_{[0,x]} * g = ∫_{Icc 0 x} g`
  (`L2.inner_def`, `inner` on ℝ is `*`; `MeasureTheory.integral_indicator` /
  `setIntegral` rewrites; `indicatorConstLp_coeFn`).
- `sobolevH01_apply_zero`: `Icc 0 0 = {0}`, measure zero ⇒ integral 0 (or
  `sobolevInd 0` is a.e. 0).
- `sobolevH01_apply_one`: `Icc 0 1` is the whole (restricted) space, so
  `f 1 = ∫ g = ⟪sobolevOne, g⟫ = 0` by membership in the orthogonal complement
  (`Submodule.mem_orthogonal`).  Note `sobolevOne` vs `𝟙_{Icc 0 1}`: they agree a.e.
  for the restricted measure (`indicatorConstLp` congruence;
  `Measure.restrict_apply`, `ae_restrict_iff`).
- `sobolevH01_kernelFun`: candidate `k_x := sobolevInd x − x • sobolevOne`; check
  (a) membership: `⟪sobolevOne, candidate⟫ = x − x·1 = 0` (compute
  `⟪1, 𝟙_{[0,x]}⟫ = volume(Icc 0 x ∩ Icc 0 1) = x` and `⟪1,1⟫ = 1`);
  (b) reproducing: for `g` in the carrier, `⟪candidate, g⟫ = ⟪sobolevInd x, g⟫ = f x`
  since `⟪sobolevOne, g⟫ = 0`.  Then invoke uniqueness of the Riesz representative:
  `kernelFun` is characterized by `⟪k_x, f⟫ = f x` for all `f` (use
  `inner_kernelFun` from `RKHS/Basic.lean` + `ext_inner_right` on the subtype).
- `sobolevH01_scalarKernel`: `K(x,y) = ⟪k_x, k_y⟫`; expand the four inner products:
  `⟪𝟙_{[0,x]}, 𝟙_{[0,y]}⟫ = min x y`, cross terms `= xy`, `⟪1,1⟫ = 1` ⇒

## Note on `sobolevKernelFun` / `sobolevScalarKernel`

These wrappers pass the carrier's `CompleteSpace` instance explicitly
(`sobolevH01CompleteSpace`), because bare TC synthesis records a different (defeq but
not instance-transparent) uniformity than `kernelFun`'s slot expects.  They are
definitionally `kernelFun SobolevH01 x` / `scalarKernel SobolevH01 x y`.  Work with
them by `unfold sobolevKernelFun sobolevScalarKernel` (or `show`/`change`) and then use
the generic `RKHS/Basic.lean` lemmas (`inner_kernelFun` etc.) — they apply to any
instance form once the goal is stated with the explicit instance.
