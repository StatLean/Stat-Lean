## Priority 1 — `LindebergCLT` (the load-bearing brick)

Mathlib has **no** triangular-array CLT (only the i.i.d. `tendstoInDistribution_inv_sqrt_mul_sum_sub`), so this file is new infrastructure that four downstream results depend on. Targets, in order:

- `lindeberg_clt` — rows independent (`iIndepFun`), centered, `MemLp _ 2`, row variances → 1, Lindeberg condition ⇒ row sums ⇒ standard normal. Route: characteristic functions. Bound `|∏ᵢ φₙᵢ(t) − exp(−t²/2)|` by a telescoping/swapping sum of third-order remainders split at level `ε`; then Lévy continuity (`MeasureTheory.ProbabilityMeasure.tendsto_iff_tendsto_charFun`) converts pointwise `charFun` convergence into convergence in distribution. The repo's multivariate CLT (`AsymptoticStatistics/ForMathlib/MultivariateCLT`) uses this same Lévy step — read it for the idiom, don't import it.
- `lindeberg_clt_of_bounded` — for `|Xₙᵢ| ≤ cₙ → 0` the Lindeberg sums are eventually empty, so this is a corollary. No `MemLp` hypothesis is present and none is needed (bounded measurable on a probability space is `L²`) — don't add one.
- `weighted_iid_clt` — negligibility is stated `∀ ε > 0, ∀ᶠ n, ∀ i, wₙᵢ² ≤ ε ∑ⱼ wₙⱼ²` rather than with `⨆` on purpose (a real `iSup` over an empty row collapses to junk `0`). Keep that form.
- `triangular_wlln_of_L1` — row laws converge weakly and first absolute moments converge ⇒ row averages → the limiting mean in probability.
