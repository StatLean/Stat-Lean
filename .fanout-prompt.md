## Proof roadmap (HDP pp. 223–226; book proof of Thm 8.1.4)
- WLOG mean-zero one-sided: fix any `t₀ ∈ T`; `⨆ t X t ω ≤ X t₀ ω + ⨆ t (X t ω − X t₀ ω)`; `∫ X t₀ = 0` kills the first term (this is where `hint`/`hmean` enter — increments have genuine means by integrability).
- Dyadic chaining: scales `ε_k = 2^{−k}`, `k` from the coarse `κ` (singleton net, `2^{−κ} ≥ diam T`) down to a finest scale where the net IS `T` (finite `T`: below the minimal positive distance, `coveringNumber = |T|` and the chain terminates — `DyadicNets` lemmas). Chain decomposition: `X t − X t₀ = ∑_k (X π_k(t) − X π_{k−1}(t))` (telescoping along closest-point projections; `π_κ` constant = the singleton net point; reconnect that point to `t₀` — for the mean-zero form the book's version anchors at the singleton, so `t₀`-freedom comes via the sup).
- Increment control: `d(π_k(t), π_{k−1}(t)) ≤ d(π_k t, t) + d(t, π_{k−1} t) ≤ ε_k + ε_{k−1} = 3·ε_k ≤ 2·ε_{k−1}`; per level the pair `(π_k(t), π_{k−1}(t))` ranges over ≤ `N_k · N_{k−1} ≤ N_k²` pairs, each `ψ₂`-bounded by `K·2ε_{k−1}` — apply the per-level finite max bound (`FinsetMaximal`/`PsiTwoMaximal`) to get `E max_pairs ≤ C·K·ε_{k−1}·√(log N_k²) = C'·K·ε_k·√(log N_k)`.
- Sum over levels: `∑_k 2^{−k}·√(log 𝒩(T,2^{−k})) = dudleySum T` (window-sum lemmas in `EntropySum.lean`); track the constant to land ≤ `6√3` — the `√3` comes from the B2 proxy `3(K·d)²` in the per-level sub-Gaussian max (`expectation_max_finset_le` with proxy `σ² = 3(2Kε)²` gives `√(2σ² log N) = 2√6·Kε√log N`… the docstring of the stub records the exact frozen bookkeeping: follow it; if the honest constant beats 6√3, still state ≤ 6√3 by weakening at the end).
